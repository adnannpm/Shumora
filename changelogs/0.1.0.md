# Shumora 0.1.0

## Workspace

- Work with independent Pi Coding Agent sessions in closable tabs.
- Arrange sessions in two tab groups, side by side or top to bottom.
- Resize groups, move tabs between groups, or merge them without restarting Pi.
- Confirm before stopping and closing a running session.

## Appearance and navigation

- Navigate between AI Workspace and Settings with a collapsible sidebar.
- Choose a light or dark application theme, saved on this device.
- Keep terminals dark independently of the application theme.

## Release notes

- Read these notes when opening this version for the first time.
- Reopen the same notes from Settings → About.

## Requirements and limitations

- Pi must be installed separately and configured with access to a model provider.
- This is an early MVP. Workspace layouts and Pi process state are not restored after exit.
- Installers are unsigned unless signing is configured separately. Platform packaging does not imply that every runtime scenario has been tested.
